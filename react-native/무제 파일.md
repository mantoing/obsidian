### React-native 실행

먼저 react-native를 실행하기위해선 **node.js**를 설치해야한다.

설치를 하고 난 후에 

``` shell
	npm install -g expo-cli
```

위 명령어를 실행하게 된다면 expo-cli가 설치가 된것이다.

![[스크린샷 2024-07-24 오후 5.05.45.png]]

위 처럼 expo 명령어를 실행 시킨후 터미널에 이런 형식의 글들이 나온다면 정상적으로 설치가 된것이다.

정상적으로 설치가 되었다면 시스템 내 새 프로젝트를 생성하고자 하는 위치에 가서 

``` shell
	npx create-expo-app
```

명령어를 실행하게 되면 프로젝트의 최초 세팅이 시작된다.

그리고 
```shell
	npm start
```

을 실행하게 된다면 프로젝트가 실행되고 실행이 된다.
이후 개발 진행과정을 확인하고 싶다면 expo 앱을 다운받아 qr코드에 접속하면 된다.
